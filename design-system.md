# Дизайн-система: Кибер.рыцарь (OZON БАНК × funtech)

Документ — **единственный источник правды** для визуала мини-аппа. При вёрстке и правках UI в Cursor указывай в запросе **`@design-system.md`**; для копирования значений в код используй **`@styles/main.css`** (блок `:root` синхронизирован с этим файлом).

## Принципы

- **Тон:** игровой, слегка ироничный; на «ты». Визуал — **чистый финтех + лёгкий «кибер/рыцарь»** без кича: акценты сдержанные, читаемость важнее эффектов.
- **Текст:** минимум; больше иллюстраций и иконографии.
- **Доступность:** контраст текста к фону ≥ **WCAG AA** для основного текста; интерактивные элементы не меньше **44×44 px** зоны тапа (через `min-height` / padding).
- **Движение:** уважать `prefers-reduced-motion` (в коде — отключать или сокращать анимации).

## Использование в Cursor

Пример запроса:

`@design-system.md сделай экран перехода между этапами`

Не выдумывай новые цвета и шрифты: бери **только** токены `--ds-*` и описанные ниже классы. Если чего-то не хватает — сначала **добавь токен в `styles/main.css` и строку в этот файл**, потом используй.

## Типографика

Шрифт стека по умолчанию (без внешних загрузок):

`system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans", sans-serif`

| Стиль | Класс (опционально) | Размер / вес |
|--------|---------------------|----------------|
| Eyebrow | `.ds-eyebrow` | `0.75rem`, `600`, `letter-spacing: 0.08em`, UPPERCASE, цвет `text-muted` |
| Заголовок экрана | `.ds-title` | `1.75rem`, `700`, `line-height: 1.2` |
| Подзаголовок | `.ds-lead` | `1rem`, `400`, цвет `text-secondary` |
| Тело | `.ds-body` | `0.95rem`, `400`, цвет `text-secondary` |
| Мелкий UI | `.ds-caption` | `0.8rem`, `600`, caps у прогресса в шапке |

Заголовки в модалках онбординга: **1.25rem**, `700`.

## Отступы и сетка

Базовая единица **4px**. Используй только:

`--ds-space-1` … `--ds-space-8` (см. `main.css`).

Горизонтальные отступы экрана: **`--ds-space-6`** (1.5rem). Вертикальные зазоры между блоками на экране: **`--ds-space-4`**–**`--ds-space-5`**.

## Радиусы и тени

- Карточки / панели: **`--ds-radius-lg`**
- Кнопки-«пилюли»: **`--ds-radius-pill`**
- Мелкие контролы (sound): **`--ds-radius-md`**
- Тень модалки: **`--ds-shadow-lg`**
- Тень карточки: **`--ds-shadow-md`**

## Компоненты (CSS-классы)

Имена **фиксированы** — новые экраны используют их, а не произвольные цвета.

### Кнопки

- `.btn` — база: `font: inherit`, `cursor`, `border-radius: var(--ds-radius-pill)`, padding из токенов, `min-height` для тап-зоны.
- `.btn--primary` — заливка `accent`, текст `on-accent`, hover `accent-hover`.
- `.btn--secondary` — фон `accent-subtle`, текст `accent`, без белой заливки.
- `.btn--ghost` — прозрачный фон, текст `text-muted`; hover лёгкий фон.
- `.btn--block` — `width: 100%` (опционально).

Ссылки-кнопки (CTA) оформляются **теми же классами**, что и `<button>`.

### Оболочка приложения

- `.shell` — колонка на всю высоту, фон **градиент** из `--ds-color-page-0/1/2`, `min-height: 100dvh`.
- `.shell__header` — стеклянная панель: фон `surface-glass`, нижняя граница `border-subtle`, `backdrop-filter`.
- `.shell__progress` — подпись этапа (eyebrow-стиль).
- `.shell__progress--muted` — название приложения на интро/финале.
- `.shell__sound` — икон-кнопка звука: покой `ghost-hover`, при наведении `accent-subtle`.
- `.shell__main` — область контента; `position: relative` для модалок **внутри** оболочки (не перекрывать шапку).

### Экраны (центрированный контент)

- `.screen` — flex-колонка, центр, `max-width: var(--ds-screen-max)`, padding `--ds-space-6`.
- `.screen--game` — чуть уже: `max-width: var(--ds-screen-game-max)`.
- `.screen__eyebrow` — опционально; дублирует `.ds-eyebrow` или используй напрямую `.ds-eyebrow`.
- `.screen__title` → предпочтительно `.ds-title` внутри разметки (или оставь семантику `screen__*` — цвета только из токенов).
- `.screen__lead` — как `.ds-lead`.

### Модалка / оверлей (онбординг 1–2 карточки)

- `.overlay` — **absolute** внутри `.shell__main`, фон `scrim`, flex-центр, padding `--ds-space-4`.
- `.overlay__panel` — фон `surface`, радиус `radius-lg`, тень `shadow-lg`, `max-width: var(--ds-modal-max-w)`.
- `.overlay__title` — заголовок модалки.
- `.overlay__text` — описание; цвет `text-secondary`.

**Карточки онбординга (1–2 шт.):** оборачивай в `.onboarding-card` внутри панели: фон `--ds-color-accent-subtle` или нейтральный `surface` с бордером `border-subtle`, радиус `--ds-radius-md`, padding `--ds-space-4`. Иллюстрация: слот `.onboarding-card__visual` (фиксированная высота, `border-radius`, фон плейсхолдера).

### Переход между этапами (междуигровой экран)

Используй `.screen` +:

- `.ds-title` — например «Новый доспех».
- `.ds-lead` — один короткий абзац про инструмент Ozon Bank (без простыней).
- Блок **слота под анимацию доспеха**: `.reward-visual` — квадрат/соотношение сторон заданное токеном `--ds-reward-visual-height`, фон `accent-subtle`, радиус `lg`, опциональная обводка `knight`.
- Первичное действие: `.btn.btn--primary` «Продолжить».

### Списки

- `.screen__list` — выравнивание влево, маркеры стандартные, цвет `text-secondary`, межстрочный интервал через `space-2`.

## Запрещено без обновления дизайн-системы

- Сырые hex/rgb в компонентах для **фона текста кнопок** (кроме редких одноразовых хаков с комментарием `/* exception: reason */`).
- Новые размеры шрифтов вне шкалы (используй rem из токенов или кратно 0.25rem).
- `position: fixed` на полноэкранный оверлей **внутри mini-app** — ломает шапку; только **absolute** в `.shell__main`.

## Кибер-экраны (макет `reference/screens.html`)

Полноэкранные сцены «телефона» используют **дополнительные** токены `--ds-cyber-*` в `styles/main.css` и классы с префиксом **`cyber-`** в `src/cyber/cyber-screens.css`. Логика и копирайт этапов — `src/content/stageContent.ts`, компоненты — `src/cyber/*.tsx`.

**Референс вёрстки (4 экрана + переключатель):** `reference/screens.html` — Главный → Этап → Результат → Финал. В приложении тот же визуальный язык: `CyberScreenMain`, `CyberScreenStagePrep`, `CyberScreenStageResult`, `CyberScreenFinal`.

В запросах к агенту: `@design-system.md` + при необходимости `@styles/main.css`, **`@reference/screens.html`**, **`@src/cyber/cyber-screens.css`**.

## Синхронизация с кодом

После изменения токенов:

1. Обнови **`:root`** в `styles/main.css`.
2. Обнови таблицы/описания в **`design-system.md`**.
3. Проверь `src/app/app.css` — классы должны ссылаться на `var(--ds-*)`.
